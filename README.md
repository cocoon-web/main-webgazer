Este toolkit se lanza como acceso abierto para conmemorar los [**20 años del Proyecto El Pez Volador (2006-2026)**](https://elpezvolador.org/2006-2026).

## 🔍 Descripción General
**MAIN-WebGazer** es un toolkit de código abierto que integra el **Multilingual Assessment Instrument for Narratives (MAIN)** ([https://main.leibniz-zas.de/](https://main.leibniz-zas.de/)) con seguimiento ocular (*eye-tracking*) basado en webcams mediante `WebGazer.js`. Integramos la potencia de MAIN con la biometría accesible para identificar la **disyunción Gaze-IST** (brecha entre lenguaje de estados internos y atención visual).

## 📜 Protocolo de Uso y Autorización (¡Muy Importante!)
El uso de este toolkit **no otorga autorización automática** para el uso de los materiales protegidos de MAIN. Cada equipo de investigación es responsable de cumplir con los siguientes pasos:
1.  **Solicitud de Materiales:** Visite la web oficial de MAIN: [https://main.leibniz-zas.de/](https://main.leibniz-zas.de/).
2.  **Formularios:** Debe completar los formularios correspondientes en dicha web para solicitar la autorización de uso de los materiales originales: [https://www.leibniz-zas.de/index.php?id=964](https://www.leibniz-zas.de/index.php?id=964)
3.  **Ejemplo en el Repo:** En esta versión, se incluyen las láminas de **"El Gato"** únicamente como ejemplo de implementación. Para acceder al set completo de materiales (Baby Birds, Truck, etc.), debe remitirse a los autores originales.

## 🛠️ Inicio Rápido
1.  **Ejecutar servidor local**: `python -m http.server 8000` (o la ruta de tu motor Python).
2.  **Abrir**: `localhost:8000/main-webgazer.html` en Chrome.
3.  **Calibrar**: 5 clics por cada uno de los 9 puntos rojos.

## 🌎 Overview (English)

## 🌟 20th Anniversary Contribution
This toolkit is released as open-access to commemorate [**20 years of the El Pez Volador Project (2006-2026)**](https://elpezvolador.org/en/2006-2026).

## 🔍 Project Overview
**MAIN-WebGazer** is an open-source toolkit that integrates the **Multilingual Assessment Instrument for Narratives (MAIN)** ([https://main.leibniz-zas.de/](https://main.leibniz-zas.de/)) with webcam-based eye-tracking using `WebGazer.js`. We combine MAIN's clinical depth with accessible biometrics to identify the **Gaze-IST disjunction** (the gap between internal state language and visual attention).

## 📘 Project Guides
* 📖 **[Guide for Children: Aura Eye Mission!](GUIDE-FOR-CHILDREN.md)**
* 📘 **[Guide for Researchers and Educators](GUIDE-FOR-RESEARCHERS-AND-EDUCATORS.md)**

## 📜 Authorization and Usage Protocol (Crucial!)
Using this toolkit **does not imply automatic authorization** to use MAIN’s copyrighted materials. Every research team is strictly required to:
1.  **Request Materials:** Visit the official MAIN website: [https://main.leibniz-zas.de/](https://main.leibniz-zas.de/).
2.  **Application Forms:** You MUST fill out the required forms on their website to request permission to use the original assessment materials: [https://www.leibniz-zas.de/index.php?id=964](https://www.leibniz-zas.de/index.php?id=964)
3.  **Repository Example:** This version includes the **"The Cat"** story images only as an implementation example. To access the full suite (Baby Birds, Truck, etc.), please contact the original authors.

## 🛠️ Quick Start
1.  **Run a local server**: `python -m http.server 8000`.
2.  **Open**: `localhost:8000/main-webgazer.html` in Chrome.
3.  **Calibrate**: 5 clicks per point (9-point protocol).
